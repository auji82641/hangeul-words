hangeul-words.vercel.app · 한국 시간 기준 · 개인정보와 직접 넣은 낱말은 모으지 않아요

비밀번호

Vercel에 넣어 둔 STATS_KEY 값을 입력하세요. 이 기기에 기억해 둘게요.

통계 저장소 연결이 필요해요

  1. Vercel → hangeul-words 프로젝트 → Storage → Create Database → Upstash for Redis(무료) → 이 프로젝트에 연결
  2. Settings → Environment Variables에 이름 STATS_KEY, 값은 원하는 비밀번호를 넣고 저장
  3. Deployments에서 맨 위 배포의 ⋯ → Redeploy
